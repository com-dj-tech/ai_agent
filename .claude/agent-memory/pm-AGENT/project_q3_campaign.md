3분기 신규 마케팅 캠페인, 메인 메시지 "일상 속 편리함"이 실행업무 DB(database_id: 736fbc07-f533-4d91-b49d-75fc816b3c8b)에 팀원별 실행 태스크로 등록되어 진행 중이다. [[project-vegan-lipbalm-launch]]와는 별개의 프로젝트.

**팀 구성 및 담당 (2026-07-10 기준 확인):**
- 김민지 팀장: 캠페인 전체 방향 검토·승인 (담당자별 실행안 취합 후 승인) — 마감 2026-07-17, 진행중, 우선순위 높음
- 이준호 대리: 광고 운영 계획 수립 및 예산 관리 (인스타그램·블로그·유튜브 쇼츠 채널 예산 배분 포함) — 마감 2026-07-17, 시작 전, 우선순위 중간
- 박서연 주임: 캠페인 기획안 작성 및 카피라이팅 (제품 중심이 아닌 '사용 장면 중심' 이미지 컨셉) — 기획안 확정 7월 3주차, 촬영 콘티·카피라이팅 완료 7월 말, 진행중, 우선순위 높음
- 최현우 사원: 경쟁사 사례 조사 및 SNS 채널 데이터 정리 — 마감 2026-07-15

**Why:** 김민지 팀장의 최종 승인이 이준호·박서연 두 실행안 취합을 전제로 하므로, 두 실행안 진행 상황이 승인 일정의 병목이 될 수 있음.
**How to apply:** 이후 이 프로젝트 관련 요청 시 위 담당자·마감·상태를 기준으로 중복 조회/등록을 피하고, 진행상황 추적은 execution-task-manager, '사용 장면 중심 이미지'나 '채널별 예산 배분' 관련 지원 조사는 notion-task-research-agent로 배정하는 패턴을 유지.
